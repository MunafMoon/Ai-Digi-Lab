# Implementation Plan

## Phase 1

- Repository setup, Docker Compose, PostgreSQL, Redis, MinIO.
- Prisma schema and seed data.
- Authentication: signup, login, refresh, logout, email verification token creation, password reset token creation.
- Organization creation and membership listing.
- RBAC middleware and tenant-scoped API helpers.
- Initial React app shell with onboarding/dashboard surfaces.

## Phase 2

Projects, tasks, task drawer, comments, Kanban board, optimistic updates, and activity log.

## Phase 3

Sprints, backlog, epics, roadmap, and calendar.

## Phase 4

AI provider abstraction, tool calling, AI chat, task generation, and task breakdown.

## Phase 5

AI planning, prioritization, standups, project health explanations, sprint summaries, and retrospectives.

## Phase 6

Documents, embeddings, RAG, semantic search, reports, and notifications.

## Phase 7

Billing architecture, AI usage limits, admin controls, and security hardening.

## Phase 8

Landing page, onboarding polish, tests, performance, and production deployment.
